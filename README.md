# noteEveryWhere

Compose Multiplatform 기반의 일정 관리 앱 기획 및 개발 문서 vault입니다.

## 목표

Android, iOS, macOS에서 사용할 수 있는 일정 관리 앱을 설계하고, 기획 문서와 기술 결정을 Codex, Obsidian, Git으로 관리합니다.

## 문서 구조

- `00-inbox/`: 빠르게 수집한 아이디어와 미정리 메모
- `01-planning/`: 제품 기획, 요구사항, 사용자 시나리오
- `02-design/`: UX, 화면 설계, 정보 구조
- `03-tech/`: Compose Multiplatform, 아키텍처, 데이터 모델, 동기화 전략
- `04-decisions/`: 주요 의사결정 기록
- `05-meetings/`: 회의록과 작업 기록

## 운영 방식

1. Obsidian에서 문서를 작성합니다.
2. Codex로 문서 정리, 구조화, 비교, 초안 생성을 요청합니다.
3. Git commit으로 변경 이력을 남깁니다.
4. 원격 저장소를 연결한 뒤 push/pull로 동기화합니다.
