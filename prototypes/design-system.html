noteEveryWhere Design System

Theme Draft

Milestone 1 화면 구현 전에 사용할 Pretendard 기반 Theme 초안입니다. Android, iOS, macOS 모두 하나의 DesignSystem을 공유하고, 플랫폼 차이는 adaptive layout으로 처리합니다.

Platform Policy

Android
Shared token을 사용합니다. 화면 폭, system inset, sheet 표현만 조정합니다.
iOS
Shared token을 사용합니다. safe area와 sheet/full-screen 표현만 조정합니다.
macOS
Shared token을 사용합니다. window, sidebar, detail layout만 expanded 기준으로 조정합니다.
