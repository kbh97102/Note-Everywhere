# macOS Home Feature Spec

## Status

Draft

## Prototype

`prototypes/macos-home.html`

## Screen Role

macOS 홈 화면은 사용자가 앱을 열었을 때 가장 먼저 보는 작업 중심 화면입니다. 오늘 해야 할 할일을 시간 조건에 따라 확인하고, 선택한 할일의 상세 정보를 오른쪽 패널에서 바로 확인하는 것을 목표로 합니다.

## Primary User Goals

- 오늘의 할일을 빠르게 파악한다.
- 특정 할일을 선택해 제목, 메모, 진행 정도, 일정을 확인한다.
- 새 할일을 빠르게 추가한다.
- 날짜를 이동해 다른 날의 일정을 확인한다.
- 로컬 변경과 동기화 상태를 인지한다.

## H-001 Today Summary

### Purpose

오늘 처리해야 할 항목의 규모를 한눈에 보여줍니다.

### Content

- 날짜: 예시 `2026년 6월 6일 토요일`
- 제목: `오늘 할일`
- 요약 칩: `할일 N개`, `완료 N개`

### Excluded

- 집중 시간 요약은 홈 화면의 초기 범위에서 제외합니다.

### Behavior

- 날짜가 바뀌면 할일 수와 완료 수가 함께 갱신됩니다.
- 할일 수는 해당 날짜에 노출되는 Task를 기준으로 계산합니다.
- 완료 수는 해당 날짜에 노출되는 Task 중 `progress = done`인 항목을 기준으로 계산합니다.

### Empty State

- 노출할 할일이 없으면 요약 칩은 `할일 0개`, `완료 0개`로 표시합니다.
- 중앙 리스트에는 빈 상태 메시지와 새 할일 추가 동작을 제공합니다.

## H-002 Task List

### Purpose

오늘의 할일을 시간 조건에 따라 확인하는 핵심 영역입니다.

### Content

- 시간대 그룹: `오전`, `오후`
- 각 할일 카드:
  - 시작 시간
  - 마감 시간
  - 제목
  - 메모 요약
  - 진행 정도

### Behavior

- 기본 정렬은 `schedule.startAt`이 빠른 순서입니다.
- `schedule.startAt`이 없고 `schedule.dueAt`만 있는 할일은 마감 시간이 빠른 순서로 배치합니다.
- 시간 조건이 없는 할일은 리스트 하단에 배치합니다.
- 선택된 할일은 카드 배경과 좌측 강조선으로 표시합니다.
- `progress = done`인 할일은 완료 상태로 표시합니다.

### Grouping Rule

- `00:00`부터 `11:59`까지는 오전입니다.
- `12:00`부터 `23:59`까지는 오후입니다.
- 시간 조건이 없는 할일은 `시간 없음` 그룹으로 분리할지 후속 결정이 필요합니다.

## H-003 Task Selection

### Purpose

리스트에서 선택한 할일을 우측 상세 패널과 연결합니다.

### Behavior

- 홈 화면 진입 시 가장 가까운 예정 할일이 기본 선택됩니다.
- 예정 할일이 없으면 첫 번째 할일이 선택됩니다.
- 사용자가 카드를 클릭하면 우측 상세 패널 내용이 즉시 갱신됩니다.
- 선택 상태는 리스트 스크롤 후에도 가능한 범위에서 유지합니다.

### Keyboard Behavior

- 위/아래 방향키로 선택 항목을 이동합니다.
- Enter로 상세 편집을 엽니다.

## H-004 Detail Panel

### Purpose

선택한 할일의 주요 정보를 화면 전환 없이 검토합니다.

### Content

- 할일 제목
- 진행 정도
- 시작기간과 마감기한
- 메모
- 하단 액션: 진행 정도 변경, 편집

### Behavior

- 할일 선택이 바뀌면 패널 내용이 갱신됩니다.
- 편집 버튼을 누르면 할일 수정 modal을 엽니다.
- 진행 정도 변경은 `todo`, `inProgress`, `done` 중 하나로 바꿉니다.

### Empty State

- 선택 가능한 할일이 없으면 오늘의 빈 상태와 새 할일 추가 버튼을 보여줍니다.

## H-005 Progress Change

### Purpose

할일의 진행 정도를 빠르게 바꿉니다.

### Content

- `todo`
- `inProgress`
- `done`

### Behavior

- 진행 정도를 바꾸면 즉시 상세 패널과 리스트 카드에 반영됩니다.
- 변경사항은 로컬에 먼저 저장됩니다.
- 동기화가 필요한 경우 좌측 동기화 상태에 반영합니다.

## H-006 Add Task

### Purpose

홈 화면에서 새 할일을 빠르게 생성합니다.

### Entry Point

- 상단 툴바의 `＋ 할일` 버튼
- 키보드 단축키 후보: `Command + N`

### Behavior

- 현재 보고 있는 날짜를 기본 날짜로 사용합니다.
- 새 할일 입력은 modal로 표시합니다.
- 새 할일의 기본 진행 정도는 `todo`입니다.
- 상세 기획은 `02-design/task-create-screen.md`에서 관리합니다.

### Required Fields

- 제목

### Optional Fields

- 메모
- 시작기간
- 마감기한

## H-007 Date Navigation

### Purpose

오늘 외의 날짜로 빠르게 이동합니다.

### Entry Point

- 상단 이전/다음 버튼
- 좌측 미니 캘린더

### Behavior

- 이전 버튼은 하루 전으로 이동합니다.
- 다음 버튼은 하루 뒤로 이동합니다.
- 미니 캘린더 날짜를 선택하면 해당 날짜의 홈 리스트로 전환합니다.
- 날짜 이동 시 선택 할일은 새 날짜의 기본 선택 규칙을 따릅니다.

## H-008 View Switcher

### Purpose

같은 데이터를 다른 시간 단위로 확인할 수 있는 진입점을 제공합니다.

### Modes

- List
- Day
- Week

### Behavior

- 초기 프로토타입에서는 List가 기본입니다.
- Day와 Week는 별도 화면 또는 동일 영역 전환 방식으로 구현할지 결정이 필요합니다.
- macOS에서는 보기 전환 후에도 좌측 사이드바와 상단 툴바는 유지합니다.

## H-009 Sidebar Navigation

### Purpose

주요 영역으로 이동하고 현재 위치를 명확히 보여줍니다.

### Items

- Today
- Calendar
- Tasks
- Settings

### Behavior

- 현재 화면은 Today로 표시합니다.
- 각 항목의 count는 해당 영역의 미처리 또는 표시 대상 개수를 나타냅니다.
- count 기준은 영역별로 별도 정의가 필요합니다.

## H-010 Sync Status

### Purpose

사용자가 로컬 변경과 원격 동기화 상태를 이해하게 합니다.

### States

- Synced: 모든 변경사항이 저장됨
- Pending: 로컬 변경사항이 대기 중
- Syncing: 동기화 진행 중
- Failed: 동기화 실패
- Offline: 네트워크 없음

### Behavior

- 로컬 우선 저장을 전제로, 편집 직후에는 데이터가 즉시 로컬에 반영됩니다.
- 원격 동기화가 실패해도 홈 화면의 조회와 편집은 계속 가능해야 합니다.
- 실패 상태에서는 재시도 액션을 제공할지 검토합니다.

## H-011 Swipe Delete Task

### Purpose

리스트에서 할일을 빠르게 삭제할 수 있는 액션을 제공합니다.

### Entry Point

- 홈 화면 할일 리스트의 Task 카드

### Behavior

- Task 카드를 왼쪽으로 밀면 오른쪽에 `삭제` 버튼을 노출합니다.
- 한 번에 하나의 Task만 삭제 버튼 노출 상태가 될 수 있습니다.
- 다른 Task를 선택하거나 다른 영역을 클릭하면 노출 상태를 닫습니다.
- 노출된 `삭제` 버튼을 누르면 해당 Task를 삭제합니다.
- 별도 확인 dialog는 표시하지 않습니다.
- 삭제된 Task가 홈 화면에서 선택 중이었다면 다음 Task를 선택합니다.
- 다음 Task가 없으면 빈 상태를 표시합니다.

### Detailed Spec

상세 기획은 `02-design/task-swipe-delete.md`에서 관리합니다.

## Interaction Priorities

1. 할일 리스트 조회
2. 할일 선택과 상세 확인
3. 새 할일 추가
4. 진행 정도 변경
5. 날짜 이동
6. 할일 삭제
7. 보기 전환

## Open Decisions

- 진행 정도를 버튼, segmented control, 메뉴 중 어떤 UI로 바꿀지 결정해야 합니다.
- Day/Week 전환을 홈 화면 내부 상태로 볼지 별도 Calendar 화면으로 보낼지 결정해야 합니다.

- 오늘 요약

- 할일 선택

- 새 할일 추가 진입점
