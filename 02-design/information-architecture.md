# Information Architecture

## Primary Areas

- Today
- Tasks
- Calendar
- Settings

## Calendar Views

- Day
- Week
- Month
- Agenda

## Item Types

- Task
- Schedule

## Draft Navigation

- Today: 오늘의 할일
- Tasks: 전체 할일 관리
- Calendar: 시간 조건 기반 탐색
- Settings: 계정, 동기화, 알림, 표시 설정

## Deferred Areas

- Search: 할일과 메모 검색
- Routine: 반복 할일
- Memo: 독립 메모
